Icons: 64 x 64, transparent. Panels: 128 x 128, border 28; use Image.Type = Sliced. Phone: 320 x 576, use Simple. Courtyard: 1024 x 576 JPG, use Simple. No mipmaps; not CPU-readable; ASTC 6x6 on Android.

Keep labels as Unity Text or TMP rather than enlarging text baked into images. Category and nav combined sprites are compatibility versions for this project's existing UI; separate icon assets and panel textures are supplied for fully editable UI.

Character portraits, outfits, and hair thumbnails should come from the game's existing character sprites. They are gameplay content, not static UI assets, and were not replaced with the example character.

The current scene and prefabs are themed while preserving original texture GUIDs and button events. High resolution source SVGs, original texture backups, replacement-map.json, the design reference, background master, and preview are under Redesign/DressUpLight, outside Assets.

If using the kit elsewhere, import GachaDressUpLight.unitypackage or copy this folder, read theme.json, and place labels separately.
